# The Impact of the US–China Trade War on County-Level US Housing Prices

Undergraduate honors thesis, **University of Oregon, Department of Economics** (February 2026).
Author: **Griffin Hsu** · Advisor: **Woan Foong Wong**

[`Undergrad_Thesis.pdf`](Undergrad_Thesis.pdf) is the final paper. This repository contains the data pipeline, analysis notebooks, generated figures, and LaTeX regression tables used to produce it.

## Abstract

The 2018–2019 U.S.–China trade war imposed tariffs on more than $360 billion worth of Chinese goods, generating geographically uneven economic shocks across American counties. While a growing literature documents the trade war's effects on consumption, prices, and welfare, its impact on U.S. housing markets remains unstudied. This paper addresses that gap, providing the first systematic evidence on how county-level tariff exposure affected housing price growth.

Using Waugh's (2019) shift-share tariff tracker — which constructs county-level effective tariff rates by weighting nationally determined industry tariffs by each county's pre-war (2017) employment composition — I estimate a fixed-effects regression of 12-month housing price growth on tariff exposure across **61,410 county–month observations** from 2017 to 2019, controlling for local employment conditions and county and time fixed effects.

I find a statistically significant positive relationship between tariff exposure and housing price growth, with a coefficient of **0.004** (significant at the 1% level), implying that a one percentage point increase in tariff exposure is associated with a **0.4 percentage point increase in annual housing price growth**. This result is consistent with a supply-side channel in which tariffs on imported construction materials raise building costs, constraining housing supply and supporting prices. The findings complement Li et al. (2024), who document negative housing price effects in Chinese cities exposed to U.S. tariffs, and contribute to a broader understanding of how trade policy shocks propagate into local asset markets.

## Repository Structure

```
.
├── Undergrad_Thesis.pdf       # Final thesis
├── src/                       # Jupyter notebooks: data prep, regressions, figures
├── Images/                    # Figures generated by the notebooks
└── LaTeX_Tables/              # Regression tables (.tex) used in the paper
```

**Note: the datasets themselves are not committed to this repository.** The full pipeline depends on Zillow ZHVI, FHFA HPI, BLS QCEW employment files (~4,400 county CSVs per year for 2017–2019), TIGER/Line shapefiles, BEA county GDP, U.S. Census population estimates, and the county-level tariff tracker. Several of these files exceed GitHub's 100 MB per-file limit, and others (Zillow ZHVI in particular) are subject to provider terms of use that discourage redistribution.

A snapshot of the data files used for this analysis is available here:
**[Google Drive: project data folder](https://drive.google.com/drive/folders/1ltM4-ydKQp4_azd9n5SZa8yOMZPZBQps?usp=share_link)**

Download the contents of that folder into a local `Data/` directory at the repo root, then the notebooks in `src/` will run end-to-end. The original sources for each dataset are listed below if you'd rather pull fresh copies.

| Variable                            | Source                                                                                  |

None of these datasets are stored in the repository. The easiest way to get the exact files used in this analysis is the [Google Drive snapshot](https://drive.google.com/drive/folders/1ltM4-ydKQp4_azd9n5SZa8yOMZPZBQps?usp=share_link); alternatively, download fresh copies from the sources above and place them in a local `Data/` directory matching the filenames the notebooks expect (`Data/Zillow ZIP.csv`, `Data/hpi master.csv`, `Data/ustariffs-by-county.csv`, `Data/countypres_2000-2020.csv`, etc.). The QCEW per-county CSVs go into per-year folders (`2017.q1-q4.by_area/`, etc.) and are condensed by `src/Employment_condenser.ipynb` into `Data/employment_data_2017_2019_combined.csv`.

## Reproducing the Analysis

The project uses Python with Jupyter notebooks. To set up an environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install pandas numpy matplotlib seaborn statsmodels linearmodels \
            scipy geopandas shapely pyproj jupyterlab
```

Then launch:

```bash
jupyter lab
```

### Suggested run order

1. **Data preparation** — `src/Employment_condenser.ipynb` collapses the per-county QCEW CSVs into a single panel.
2. **Exploratory figures** — `src/Scatterplot.ipynb`, `src/Barplots.ipynb`, `src/Housing Line Plot.ipynb`, `src/adjusted_lineplot.ipynb`.
3. **Heat maps** — `src/Tariff Heat Map.ipynb`, `src/Zillow Heat Map.ipynb`.
4. **Robustness / data comparisons** — `src/HPI compare Zillow.ipynb`, `src/Government_comparison.ipynb`, `src/Winsorized.ipynb`.
5. **Main regressions** — `src/Housing Regression.ipynb` (base) and `src/Quartile Regressions.ipynb` (heterogeneity by tariff-exposure quartile).
6. **Geographic regression (Appendix C)** — `src/geographic_regression.ipynb`.
7. **Auxiliary** — `src/Voting.ipynb` (county vote share interactions), `src/New Houses.ipynb`, `src/Housing Prices County Plots.ipynb`.

Generated figures land in `Images/`; LaTeX regression tables land in `LaTeX_Tables/` and are `\input{}`'d directly by the thesis source.
